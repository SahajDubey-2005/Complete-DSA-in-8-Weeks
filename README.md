## 📌 About The Challenge

A rigorous **8-week intensive DSA challenge** built to master core data structures, problem-solving paradigms, and optimal coding patterns in Java. Every problem is solved with a focus on optimal time & space complexity ($O(n)$ / $O(1)$) and maintained through strict daily consistency.

---

## 📂 Repository Roadmap & Structure

```text
Complete-DSA-in-8-Weeks/
│
├── Week-01_Arrays_and_Hashing/         # Two Pointers, HashSets, Prefix Sums
├── Week-02_Sorting_and_Searching/      # Binary Search, Kth Largest Elements
├── Week-03_Strings/                    # Anagrams, Sliding Window, Pattern Matching
├── Week-04_Linked_List/                # In-place Reversals, Fast & Slow Pointers
├── Week-05_Stack_and_Queue/            # Monotonic Stacks, Parentheses, Queues
├── Week-06_Trees/                      # DFS, BFS, BST Traversals
├── Week-07_Recursion_and_Backtracking/ # Subsets, Permutations, N-Queens
└── Week-08_DP_and_Graphs/              # 1D/2D DP, Shortest Paths, Topological Sort
```
🧠 Core Topics & Focus Areas
Data Structures: Arrays, Strings, Linked Lists, Stacks, Queues, Binary Trees, Graphs, Hash Tables.

Algorithms: Two Pointers, Sliding Window, Binary Search, Recursion, Backtracking, Dynamic Programming.

Optimization Goal: Writing clean, modular, and high-performance Java code targeting optimal execution times.
